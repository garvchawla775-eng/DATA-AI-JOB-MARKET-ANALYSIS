# Data & AI Job Market Salary Analysis

A portfolio-ready data analytics project that cleans salary data, loads it into SQLite, runs SQL analysis, and generates charts that summarize Data and AI job-market trends.

## What this project answers

- How salary changes by experience level
- How Data/AI postings and average salary changed from 2020 to 2023
- Which job titles have the highest average salaries
- How remote, hybrid, and on-site work are distributed
- How company size relates to average salary
- Which Data/AI job titles appear most often

## Key findings

Based on the cleaned Data/AI subset used in this project:

- Entry-level average salary: about **$67K**
- Mid-level average salary: about **$99K**
- Senior-level average salary: about **$152K**
- Executive-level average salary: about **$189K**
- Data Engineer, Data Scientist, and Data Analyst are among the most common titles
- Remote work represents a substantial share of the dataset

See [`FINDINGS.md`](FINDINGS.md) for the tables behind the charts.

## Run locally

```bash
git clone https://github.com/garvchawla775-eng/DATA-AI-JOB-MARKET-ANALYSIS.git
cd DATA-AI-JOB-MARKET-ANALYSIS

python -m venv .venv
source .venv/bin/activate      # macOS/Linux
# .venv\Scripts\activate     # Windows

pip install -r requirements.txt
python etl.py
python analysis.py
```

`etl.py` reads the raw CSV, performs cleaning and feature engineering, writes `cleaned_salaries.csv`, and refreshes `job_market.db`.

`analysis.py` runs the SQL queries in `queries.sql`, writes the charts to `charts/`, and regenerates `FINDINGS.md`.

## Analysis pipeline

## Dataset

The project uses a public Data Science / AI salary dataset covering 2020 to 2023 and originally sourced from ai-jobs.net salary data.

The analysis filters for Data/AI-focused roles using job-title matching and removes exact duplicates, rows missing critical fields, and implausible salary values.
